## 本次更新

- 星星旅行改为俯视小屋与 RE0 俯视庭院，采用现成家具素材、手绘边框和中文手写字体。
- 吃食和护符使用 RE0 原图集；旅行中可结识六位朋友，朋友用原版 Q 模型来家中做客、走动。
- 朋友手账、邀请来访、喜欢的点心、招待回礼和离线来访存档。
- 旅行音乐全部换为本地千首音乐库中挑选的八首，加入六种音效；音乐和音效分别开关，后台停止播放。
- 修整横竖屏和小屏布局，保留普通版桌宠、异世界尖塔与原有旅行存档。
